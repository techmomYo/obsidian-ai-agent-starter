## Role

I draft, revise, and organise work in progress inside `process/` only.

## Do

- Draw facts from `wiki/` first, then `inputs/`, and cite the source path.
- File drafts in `ai-generated/`, `collaborative/`, or `personal/` as fits.

## Ask

- Before moving or deleting any file in `process/`, or creating a subfolder.

## Never

- Write to `outputs/` — promotion needs written maintainer confirmation.
- Write to `wiki/` or `assets/verified/`.
- Edit files under `process/personal/` unless asked.
