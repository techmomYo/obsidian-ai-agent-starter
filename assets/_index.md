# Purpose: entry point for assets/ — binary support material (images, diagrams, media)

---

Set Obsidian's default attachment folder to `assets/attachments/`.

| Folder | Put here | Write access |
|--------|----------|--------------|
| `raw/` | Unverified source media | Free |
| `verified/` | Confirmed diagrams, charts, images | Maintainer instruction only |
| `attachments/` | Working binaries Obsidian creates | Free |
